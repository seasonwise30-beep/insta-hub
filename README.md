# Insta Hub

A responsive Instagram profile directory starter with a dark, purple-accented interface.

## Included
- Responsive landing page and creator cards
- Client-side search and category filters
- Profile submission form with basic validation
- Setup guide for connecting a real backend

## Important
This repository currently contains a **frontend demo only**. The submission form validates input in the browser but does not send or persist submissions. Profile cards are sample content. There is no admin login or secure admin dashboard yet. Read [SETUP.md](SETUP.md) before collecting real submissions or publishing admin features.

## Run locally
Open `index.html` in a browser, or serve this folder with any static web server.

## Deploy
The frontend can be hosted on GitHub Pages. A separate backend (for example Supabase) is required for persistent submissions and admin authentication.
